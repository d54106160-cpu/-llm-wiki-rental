# 民法 第二編債 第二章各種之債 第五節租賃（來源摘要）

> 白話：民法是租賃的一般規定，從租約怎麼成立、修繕、轉租、付租金，到租期屆滿怎麼結束都有寫；與條例規定不同時，依使用者的決定以條例為準。

- 範圍：第 421 條～第 463-1 條
- 日期說明：此 PDF 為全國法規資料庫列印版，未載明租賃節各條修正日期；source_date 填的是**查詢（列印）日 2026-11-11**，不是條文修正日

## 適用前提
- 與條例規定不同時：依**使用者決定採用之一般法律原則**「特別法優於普通法」，以條例為準（此原則並非本 Wiki 來源所載，見 AGENTS.md）
- 本 Wiki 只收錄與住宅房客相關的條文；基地租賃（第 422-1、425-1、426-1、426-2 條）、動物（第 428 條）、租期上限（第 449 條）、耕作地（第 457～463 條）、權利租賃（第 463-1 條）不展開
